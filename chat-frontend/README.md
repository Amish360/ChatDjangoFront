# chat-frontend

A React app built with [Vite](https://vite.dev/).

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode with hot module reloading.\
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build from `dist` locally, for a final check before deploying.

### `npm test`

Runs the test suite with [Vitest](https://vitest.dev/).
